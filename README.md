# MY CAR CARD — الموقع التعريفي

موقع تعريفي فاخر لشركة **MY CAR CARD**، شركة تقنية سعودية تبني منظومة رقمية
متكاملة تربط ملاك السيارات بمزوّدي خدمات السيارات عبر منصة ذكية واحدة. الموقع
مبني لعرض الشركة ونموذج أعمالها وتقنيتها لإقناع الشركاء والمستثمرين — وليس
لبيع تطبيق الجوال.

## المكدس التقني

- **Next.js 15** (App Router) + **TypeScript**
- **Tailwind CSS v4** (نظام تصميم Navy / Gold فاخر)
- **Framer Motion** + **GSAP** للحركة والانتقالات
- **Lenis** للتمرير السلس (Smooth Scroll)
- **Lucide Icons**
- **Schema.org / OpenGraph / Twitter Cards** لتحسين محركات البحث

## البدء السريع

```bash
npm install
npm run dev
```

افتح [http://localhost:3000](http://localhost:3000). الموقع بالكامل مبني من
محتوى ثابت في `src/config/site.config.ts` — لا حاجة لأي إعداد إضافي أو
متغيرات بيئة لتشغيله محلياً.

### أوامر أخرى

```bash
npm run build   # بناء الإنتاج
npm start       # تشغيل بناء الإنتاج محليًا
npm run lint    # فحص الشيفرة
```

## هيكل الصفحة الرئيسية

1. **Preloader** — لودر سينمائي برسم الشعار والتوهج الذهبي
2. **Hero** — شاشة كاملة بخلفية Aurora متحركة وموك-أب جوال عائم
3. **Story** — قصة الشركة، الرسالة، الرؤية، جدول زمني، القيم
4. **Challenges** — تحديات السوق وتحويلها لحلول (بطاقات قابلة للقلب)
5. **Ecosystem** — مخطط دائري متحرك لمنظومة المنصة
6. **Solutions** — تسع بطاقات حلول تفاعلية (Tilt Cards)
7. **Technology** — البنية التقنية بتصور كروي متحرك
8. **Industries** — القطاعات التي يمكنها الانضمام
9. **Mobile App** — تطبيق الجوال كجزء من المنظومة
10. **Dashboard** — لوحة أعمال بمؤشرات ورسوم بيانية حية
11. **Partner Journey** — رحلة الشريك في ست خطوات
12. **Testimonials** — قصص نجاح الشركاء
13. **FAQ** — أكورديون فاخر
14. **Final CTA** — دعوة ختامية سينمائية
15. **Footer** — تذييل زجاجي مع نشرة بريدية وروابط التواصل

## إعادة استخدام القالب لمشروع آخر

عدّل **`src/config/site.config.ts`** فقط — يحتوي على كل المحتوى: اسم الشركة،
الألوان، الأقسام، الحلول، القطاعات، رحلة الشريك، الأسئلة الشائعة، بيانات
التواصل والروابط الاجتماعية. لا حاجة لأي تعديل بنيوي في المكوّنات أو الصفحات.

## هيكل المشروع

```
src/
  app/                 صفحات ومسارات App Router
  components/
    layout/            شريط التنقل + مزود التمرير السلس
    sections/           14 قسمًا لتدفق الصفحة الرئيسية
    ui/                 مكوّنات واجهة قابلة لإعادة الاستخدام (منها اللوجو،
                        الخلفيات المتحركة، حقل الجسيمات، بطاقات Tilt)
  config/               ملف الإعدادات المركزي (site.config.ts)
  hooks/                React hooks (عدّاد تصاعدي، إلخ)
  lib/                  دوال مساعدة وأنماط حركة مشتركة
  types/                تعريفات TypeScript المشتركة
```

## الأداء وإمكانية الوصول

- تحميل كسول وتقسيم للشيفرة (`next/dynamic`) لكل قسم أسفل الهيرو.
- هيكل عناوين دلالي، `aria-label` على العناصر التفاعلية، ودعم كامل لـ
  `prefers-reduced-motion` (تعطيل الجسيمات والحركات المكثفة تلقائياً).
- تباين ألوان يستهدف مستوى AA.
- بيانات SEO ديناميكية، Schema.org (`Organization`)، `robots.txt`،
  و`sitemap.xml`.

## ملاحظة حول الوسائط

جميع الخلفيات والرسوم في هذا الإصدار مبنية بالكامل بالكود (SVG / Canvas /
CSS gradients) نظرًا لعدم توفر تصوير أو فيديو سينمائي حقيقي للشركة عند بناء
القالب. عند توفر تصوير فعلي (فيديو الهيرو، صور الفريق، شهادات فيديو
الشركاء)، يمكن استبدال هذه العناصر داخل المكوّنات المعنية في
`src/components/sections/` دون تغيير بنية الصفحة.
