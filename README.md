# تاون هاوس القادسية — فواصل المستقبل

موقع تعريفي فاخر لمشروع **تاون هاوس القادسية** (فواصل المستقبل)، مبني كقالب Next.js
قابل لإعادة الاستخدام لأي مشروع عقاري سعودي مستقبلي.

## المكدس التقني

- **Next.js 15** (App Router) + **TypeScript**
- **Tailwind CSS v4**
- **Framer Motion** + **GSAP** للحركة والانتقالات
- **Embla Carousel** لمعرض الصور
- **React Hook Form** + **Zod** (جاهزة للنماذج المستقبلية)
- **Lucide Icons**
- **Google Sheets API** (googleapis) للوحدات ولوحة التوفر المباشرة
- **Schema.org / OpenGraph / Twitter Cards** لتحسين محركات البحث

## البدء السريع

```bash
npm install
cp .env.example .env.local   # عدّل القيم إن رغبت بربط Google Sheets
npm run dev
```

افتح [http://localhost:3000](http://localhost:3000). في حال عدم ضبط بيانات Google
Sheets، يعمل الموقع تلقائيًا ببيانات تجريبية مطابقة لهيكل المشروع الحقيقي (18 وحدة).

### أوامر أخرى

```bash
npm run build   # بناء الإنتاج
npm start       # تشغيل بناء الإنتاج محليًا
npm run lint    # فحص الشيفرة
```

## ربط Google Sheets (لوحة التوفر + الوحدات)

1. أنشئ مشروع Google Cloud وفعّل **Google Sheets API**.
2. أنشئ **Service Account** وحمّل مفتاح JSON الخاص به.
3. شارك الجدول (Google Sheet) مع بريد الـ Service Account بصلاحية **Viewer**.
4. اضبط الأعمدة بالترتيب التالي بدءًا من الصف الثاني (`A2:J...`):

   | العمود | الوصف |
   | --- | --- |
   | A | Unit ID (رقم الوحدة) |
   | B | Status (`متاح` / `محجوز` / `مباع`) |
   | C | Area (المساحة بالمتر) |
   | D | Price (السعر) |
   | E | Bedrooms (غرف النوم) |
   | F | Bathrooms (دورات المياه) |
   | G | Parking (المواقف) |
   | H | Roof (مساحة الأسطح) |
   | I | Image (رابط صورة الوحدة) |
   | J | PDF (رابط ملف PDF الخاص بالوحدة، اختياري) |

5. عبّئ متغيرات البيئة في `.env.local`:

   ```
   GOOGLE_SHEET_ID=xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
   GOOGLE_CLIENT_EMAIL=your-service-account@project.iam.gserviceaccount.com
   GOOGLE_PRIVATE_KEY="-----BEGIN PRIVATE KEY-----\n...\n-----END PRIVATE KEY-----\n"
   GOOGLE_SHEET_RANGE=Units!A2:J100
   ```

أي تعديل على الجدول ينعكس تلقائيًا على الموقع (يُعاد الجلب كل 30 ثانية عبر
`/api/units` و`/api/availability`، بدون أي إعادة تحميل للصفحة).

### سلوك الموقع حسب حالة الربط

| الحالة | السلوك |
| --- | --- |
| متغيرات البيئة فارغة (لم يتم الربط بعد) | يعمل الموقع تلقائيًا ببيانات تجريبية مطابقة لهيكل المشروع الحقيقي (18 وحدة) |
| تم الربط والجدول يستجيب بشكل طبيعي | تُعرض بيانات Google Sheets الحقيقية مباشرة |
| تم الربط لكن الطلب فشل (صلاحيات، معرّف خاطئ، انقطاع شبكة) | تُعاد قائمة وحدات فارغة ولوحة توفر بقيم صفرية بدلًا من تعطّل الصفحة أو ظهور خطأ 500 — الخطأ يُسجَّل في سجلّات الخادم فقط (`console.error`) ولا يظهر للزائر |

بيانات الاعتماد (`GOOGLE_CLIENT_EMAIL`, `GOOGLE_PRIVATE_KEY`) تُقرأ فقط داخل
ملفات خادمية (`src/services/googleSheets.ts`, `src/services/units.ts`، ومسارات
`app/api/*`) ولا تُستورد أبدًا من أي مكوّن يعمل على المتصفح (`"use client"`)،
فلا تصل إلى الواجهة الأمامية بأي شكل.

## إعادة استخدام القالب لمشروع آخر

تم بناء الموقع بحيث لا تحتوي أي مكوّنات على محتوى خاص بمشروع بعينه. لإطلاق
مشروع عقاري جديد بنفس القالب:

1. عدّل **`src/config/site.config.ts`** فقط — يحتوي على كل شيء: اسم المشروع،
   المطوّر، المسوّق الحصري، الألوان، بيانات التواصل، الإحصائيات، معرض الصور،
   المخططات، الضمانات، معالم الموقع، وروابط التواصل الاجتماعي.
2. استبدل الوسائط في `public/images` و`public/videos` بوسائط المشروع الجديد
   (الصور المرفقة حاليًا عبارة عن رسومات SVG تجريبية بديلة عن الوسائط
   الحقيقية — راجع قسم "الوسائط" أدناه).
3. عدّل متغيرات `.env.local` لربط جدول Google Sheets الخاص بالمشروع الجديد.
4. لا حاجة لأي تعديل بنيوي في المكوّنات أو الصفحات.

## الوسائط (Media Assets)

نظرًا لعدم توفر تصوير حقيقي للمشروع عند إنشاء هذا القالب، تم توليد رسومات
SVG تجريدية بألوان الهوية البصرية لتُستخدم كبدائل مؤقتة في:

- `public/images/hero-poster.svg` (خلفية الهيرو، وتُستبدل بفيديو درون عبر
  `public/videos/hero-drone.mp4` إذا توفر)
- `public/images/gallery/*.svg` (معرض الصور)
- `public/images/floor-plans/*.svg` (مخططات الأدوار)
- `public/images/logos/*.svg` (شعارا المطوّر والمسوّق)
- `public/images/og-image.svg` (صورة المشاركة على وسائل التواصل)

استبدل هذه الملفات بنفس الأسماء (أو حدّث المسارات في `site.config.ts`) عند
توفر التصوير الفعلي والشعارات الرسمية، دون أي تعديل على الشيفرة.

## هيكل المشروع

```
src/
  app/                 صفحات ومسارات API (App Router)
  components/
    layout/            شريط التنقل العلوي
    sections/           14 قسمًا لتدفق الصفحة الرئيسية
    units/              بطاقات الوحدات، الفلاتر، نافذة التفاصيل
    ui/                 مكوّنات واجهة قابلة لإعادة الاستخدام
  config/               ملف الإعدادات المركزي (site.config.ts)
  hooks/                React hooks (عدّاد تصاعدي، جلب الوحدات، إلخ)
  lib/                  دوال مساعدة وأنماط حركة مشتركة
  services/             منطق الأعمال (Google Sheets، تحويل بيانات الوحدات)
  types/                تعريفات TypeScript المشتركة
```

منطق الأعمال (جلب Google Sheets، حساب إحصائيات التوفر) معزول بالكامل داخل
`services/`، ولا تحتوي مكوّنات الواجهة على أي منطق أعمال مباشر.

## الأداء وإمكانية الوصول

- تحميل كسول وتقسيم للشيفرة (`next/dynamic`) للأقسام الأدنى من الصفحة.
- تحسين الصور عبر `next/image` مع أحجام متجاوبة.
- هيكل عناوين دلالي، `aria-label` على العناصر التفاعلية، ودعم كامل لـ
  `prefers-reduced-motion`.
- تباين ألوان يستهدف مستوى AA.
- بيانات SEO ديناميكية، Schema.org (`RealEstateListing`)، `robots.txt`،
  و`sitemap.xml`.
